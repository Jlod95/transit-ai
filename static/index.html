How this answer was made

The AI model chose which tools to call. Each tool runs our own tested Python code on the timetable data, and the model wrote the answer from what the tools returned.

    Battery size and energy use are placeholder assumptions, not sourced figures, and distances leave out empty running to and from the garage, so results are optimistic. Treat this as a first pass, not a recommendation.
    Data: Halifax Transit GTFS, under the Open Government Licence – Halifax. This demo answers a limited number of questions per visitor and per day. Source code on GitHub.
